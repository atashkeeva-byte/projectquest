# Движок текстовых квестов

## Описание проекта

Движок текстовых квестов — программа на Python для создания и прохождения текстовых приключений, сценарии которых описываются в JSON-файлах.

Основная цель проекта — разработать универсальный игровой движок, который отделяет игровую логику от содержания конкретного квеста. Благодаря этому новые приключения можно создавать и изменять без необходимости переписывать основной код программы.

Вместо того чтобы жёстко задавать сюжет, локации и предметы в Python, движок загружает их из JSON, проверяет корректность сценария, создаёт игровые объекты и предоставляет игроку набор текстовых команд.

В качестве демонстрационного примера в проект входит квест «Тайна старого маяка», в котором игрок исследует локации, собирает предметы и решает загадки.

## Возможности движка

* Загрузка сценариев из JSON. Игровой мир, описания локаций, предметы, переходы и загадки задаются в отдельном файле.
* Проверка сценария. Перед запуском проверяются обязательные поля, стартовая локация, корректность переходов, предметов и загадок.
* Работа с игровым миром. Локации содержат описания, предметы и выходы в другие локации.
* Перемещение между локациями. Игрок может исследовать мир, переходя по доступным направлениям.
* Инвентарь. Игрок собирает предметы, которые могут понадобиться для дальнейшего прохождения.
* Условия переходов. Доступ к некоторым локациям может зависеть от наличия определённых предметов.
* Загадки и награды. Сценарий может задавать вопросы, ответы и предметы, которые игрок получает за решение загадок.
* Сохранение и загрузка. Игровое состояние можно сохранить и восстановить.
* Обработка ошибок. Для некорректных сценариев и ошибок при работе с файлами предусмотрены механизмы обработки исключений.
* Расширяемость. Новые сценарии можно создавать на основе существующей структуры JSON, не изменяя основную игровую логику.

## Демонстрационный сценарий: «Тайна старого маяка»

В комплект проекта входит пример приключения, демонстрирующий работу движка.

Игрок оказывается в доме исчезнувшего смотрителя и начинает расследование тайны старого маяка. Исследуя помещения и окружающую территорию, он находит записки, ключи и другие предметы, постепенно открывает новые пути и разгадывает загадки.

Сценарий включает 10 локаций, связанные переходы, предметы, условия доступа и загадку с наградой.

Этот квест является примером использования программы, а не её основной целью. Движок предназначен для создания других текстовых приключений с собственными сюжетами, локациями и игровыми механиками.

## Используемые технологии

* Python — реализация игровой логики и объектной модели.
* JSON — описание игровых сценариев.
* pytest — автоматическое тестирование ключевых функций.

Проект использует стандартную библиотеку Python для основной функциональности. Для запуска игры сторонние библиотеки не требуются; pytest необходим для запуска тестов.

## Создание собственного сценария

Чтобы добавить новое приключение, достаточно подготовить JSON-файл в соответствии со структурой, которую поддерживает движок.

Сценарий описывает:

* start — стартовую локацию;
* locations — список локаций и их свойства;
* description — описание каждой локации;
* items — предметы, доступные в локации;
* exits — направления переходов и целевые локации;
* requires — необязательное условие перехода в виде необходимого предмета;
* riddle — необязательная загадка с вопросом, ответом и наградой.

Перед началом игры движок проверяет структуру сценария и связи между локациями. Это помогает обнаруживать ошибки в JSON до начала прохождения.

При создании нового сценария важно соблюдать формат данных, поддерживаемый загрузчиком и игровыми классами.

## Запуск программы

### Запуск игры

python main.py

После запуска программа загрузит демонстрационный сценарий и предложит ввести имя игрока.

## Игровые команды

| Команда          | Действие                        |
|------------------| ------------------------------- |
| `look`           | Осмотреть текущую локацию       |
| `go <direction>` | Перейти в указанном направлении |
| `take <item>`    | Подобрать предмет               |
| `inventory`      | Посмотреть инвентарь            |
| `riddle`         | Попробовать решить загадку      |
| `help`           | Показать список команд          |
| `save`           | Сохранить игру                  |
| `load`           | Загрузить сохранение            |
| `quit`           | Завершить игру                  |

Доступные переходы и предметы зависят от загруженного сценария.

## Тестирование

Для запуска автоматических тестов:

python -m pytest -v


Тесты проверяют ключевые части логики, в том числе корректность сценария, стартовую локацию, переходы и необходимые для них предметы, а также валидацию загадок.

## Цель проекта

Цель проекта — разработать расширяемую основу для текстовых приключений, в которой описание игрового мира хранится отдельно от программной логики.

Проект демонстрирует применение объектно-ориентированного программирования, работы с JSON, пользовательских исключений и автоматического тестирования при создании небольшого, но расширяемого приложения.
